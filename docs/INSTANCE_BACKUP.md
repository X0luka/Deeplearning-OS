# 开发实例统一备份与恢复

此入口只支持本独立准备副本的 dev-* 实例，不用于现用产品目录。
由开发人员执行，当前没有在桌面 UI 增加备份按钮，也没有自动切换实例。

## 范围
包含工作台 archive.db、统一助手 assistant/assistant.db、模型配置 llm/config.db、外观 appearance.json，以及 Reader/Wiki 各自备份接口导出的数据库、原始资料、阅读产物和笔记。
不包含 workbench/llm/private 下的 API 密钥和内部服务令牌，也不包含运行进程台账、日志、浏览器缓存、HOME、临时目录或虚拟环境。
模型地址、模型 ID、选择和偏好保留；恢复后必须重新输入密钥。内部服务令牌由新实例重新生成。
这里的密钥排除针对产品的凭据存储，不是扫描并删除论文、笔记或源码正文中任意出现的敏感内容。
备份包含用户资料且未加密，不应上传到公开仓库。

## 启动与备份互斥
开发实例启动、备份、恢复共用副本内的生命周期锁。
实例运行中、旧桌面会话锁被占用、发现仍存活的已记录子进程时，备份拒绝继续；它不会替用户停止服务。
支持经开发实例入口启动的受管进程。不得在维护期间绕过入口直接启动组件或外部脚本写数据。
组件原有 worker/artifact 锁仍保留。此机制不是不受管写入者之间的分布式事务。

## 非覆盖恢复
备份位于副本 .local/backups/<备份名>，含统一文件集合及 SHA256 清单。
恢复只接受一个不存在的开发实例名，输出到 .local/instances/<新实例名>。
先验证整包文件集合、哈希及允许路径；拒绝目录链接、额外文件、越界路径和凭据目录注入。
组件恢复从临时副本读取，避免组件生成的锁文件或 SQLite sidecar 改变原备份。
中途失败仅清理本次新建的实例；异常终止留下 .restore-in-progress 时，启动入口会拒绝启动。
工作台助手及 Wiki 排队/运行任务标为 interrupted；Reader 沿用原有中断恢复规则，不自动重试或调用模型。
Reader/Wiki 恢复沿用产品身份并更新导出 epoch，避免旧游标被误用。

## 命令形式
从独立副本根目录，以工作台自己的 Python 运行：

    components/AgentOS-K/.venv/bin/python scripts/instance_backup.py backup --instance dev-example --name before-update
    components/AgentOS-K/.venv/bin/python scripts/instance_backup.py restore --instance dev-restored --name before-update

示例实例名只是占位，不能在原产品目录运行。测试仍必须使用 scripts/run-isolated.sh。
没有输入任意系统源目录/目标目录的参数，不能把原仓库指定为操作对象。
需要关闭对应的开发实例；不需要也不应关闭现用产品。

## 验收
合成会话、部分回答、HTML 论文、Wiki 笔记、模型选择和假密钥覆盖整包演练。
覆盖资料恢复、原备份不变、私钥存储排除、恢复后缺密钥的明确错误、启动与备份互斥、已有目标保护、损坏包拒绝、恢复失败清理、未完成标记和存活遗留进程拒绝。
首次夹具曾错误使用会话返回字典代替 ID；另一项断言曾未解析 JSON 中文转义；已修正并保留日志。
磁盘满、超大资料集、系统突然断电及不受管并发写入的长期压力场景未验收。
备份格式仍是开发阶段格式，尚未承诺跨版本迁移兼容性。
