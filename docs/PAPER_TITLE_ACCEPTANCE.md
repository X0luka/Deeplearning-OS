# 论文标题发现验收

2026-10-01，合成资料、断网隔离环境，无模型调用。

## 原因与改进

arXiv 导入保留编号文件名，助手资源目录之前直接使用该文件名；因此仅按英文论文标题查询可能无结果。
现在读取来源明确声明的 citation_title / arXiv 论文标题；对于已处理的旧资料，可使用不可变内容中的首个一级标题作为回退。
资源目录返回显示标题及原名称、来源URL别名，原有目录检索即可匹配标题和编号。仍使用既有授权资源集合，不扩大工具权限。
原PDF字节、文档ID、数据库保存名称、翻译/解析内容和模型提示词不改写，不触发重新解析或付费翻译。
如果旧资料没有标题元数据或可辨识一级标题，继续显示原名；不猜测标题、不承诺拼写错误也能命中。
