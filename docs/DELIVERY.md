# 开发者源码版交付导航
日期：2026-09-30。当前为开发者源码候选版；公开仓库 X0luka/Deeplearning-OS，许可证 MIT。

## 交付内容
- 三个组件的独立源码、固定依赖与本地 Git 检查点。
- 从源码准备环境、构建 Windows 桌面壳和配置模型的指南。
- 网络规范、数据备份恢复说明、许可说明和真实验收范围。
- 源码 ZIP 与逐文件 SHA256 清单；不包含密钥、数据库、个人论文、运行缓存、Git 历史、虚拟环境或 node_modules。

默认入口为 Windows 桌面；浏览器可用于配置和备用访问。本次不交付普通用户一键安装包、自动升级或卸载器。
开发者首先阅读 [DEVELOPER_QUICKSTART.md](DEVELOPER_QUICKSTART.md)，实际验证范围见 [ACCEPTANCE_STATUS.md](ACCEPTANCE_STATUS.md)。

## 已验证的安装方式
已在同一台电脑的新源码目录中重新准备三个 Python 环境、Node、前端和 WebView2 SDK，构建桌面并由桌面自主启动专用后台。
这是新源码与新依赖目录的验证，不等同于另一台电脑或全新 Windows/WSL 的验证。
增强 PDF 的资产下载、标准解析和断点复用在独立主验收目录完成，没有为安装测试再下载整套模型。

## 两个版本的管理
现用原项目和开源副本各自保存源码、实例数据、密钥、缓存及备份。
测试通过不会自动升级现用产品。后续升级应先备份，在独立实例验证迁移与回滚，再明确决定是否替换日常入口。
不要混合两份数据库，也不要靠复制现用密钥完成开源配置。

## 公开发布方式
已按用户授权使用 X0luka/Deeplearning-OS 公开仓库，保留 MIT 及 X0luka 署名。
公开仓库应从本次最终源码快照建立新的提交历史，不直接推送本地准备仓库的历史；早期准备记录可能含已清理的本机路径。
本仓库为公开源码快照，不包含本地准备历史；没有创建新桌面快捷方式。
本地桌面测试产物只作为验证证据，不是对外分发的安装包。
