# 开发者版交付门槛

本次目标：开发者从源码准备环境，配置自己的API与网络，通过Windows桌面壳使用产品。
不以普通用户一键安装包、自动更新、卸载器作为本次门槛。

## 必须完成
- 源码目录不带密钥、个人数据库、论文、旧仓库Git历史和运行缓存。
- 依赖与模型资产版本锁定；开发者指南不依赖维护者用户名、代理端口或复制证据。
- 按指南在全新源码目录准备基础环境并验证桌面启动。
- DeepSeek真实问答、翻译和工具续接，增强PDF标准解析及断点复用。
- Wiki完整生成链路及重开、导出、缓存与恢复；说明合成输入和真实网络测试各自范围。
- 保留源码中已有的第三方许可，提供必要的构建与运行说明。
- 公开前确认目标GitHub仓库与源码许可证，检查最终上传内容；从最终源码快照建立公开历史，不直接上传本地准备历史。

## 明示支持边界，不冒充已验证
- 目前验证Windows + WSL2 Ubuntu、Linux x86_64、Python 3.12；其他组合未验收。
- Gemini为可选服务商，原生联网搜索/原始PDF模型输入未做真实付费验收。
- 当前联网验收使用显式代理；无透明代理的纯直连环境未验收。
- 小型合成Wiki项目不代表所有大型真实仓库的质量保证；实际代码下载另有网络验收。
- PDF已验证15页样本的标准解析和恢复，不代表所有版式或逐公式均无误。
- 开发者Beta需保留可恢复数据和错误信息，不自动覆盖用户已有产品。

这些边界必须随开发者版说明交付；不能把未验证能力写成已通过，也不应无限扩大为所有系统和网络都验证后才能发布。
