## 内容抽查
对照合成文件，正文正确说明了：
- 只有 valid 页面写入完成集合，无效页不标记完成。
- 重启读取检查点，第二轮仅验证尚未完成的页。
- 同目录临时文件加 replace 与 fsync/掉电持久性有区别。
- retry_allowed 只对 not_sent 为真，uncertain 不可自动重试；没有把谓词当作实际计费对账实现。
- 示例没有 PDF 解析或模型调用，不把演示代码夸大为完整处理系统。

架构总览把调用方验证函数作为接口边界展示；它不等于另一个进程或远程服务。生成解释仍需结合源码判断。
本次抽查不是对全部文字无误的保证，也不代表大型真实仓库质量。
