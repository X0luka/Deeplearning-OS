# GitHub Wiki
本地 GitHub 源码阅读产品：固定版本快照、中文阅读目录、静态 Python 模块依赖、可追溯的源码检索、可配置模型问答及历史归档。

## 从 AgentOS 打开
将本项目放在 AgentOS-K 的相邻目录，首次安装：
~~~bash
cd ~/code/GitHub-Wiki
uv sync --frozen --extra dev
cd ../AgentOS-K
.venv/bin/python -m aos.bootstrap serve
~~~
打开 http://127.0.0.1:7777，点击 GitHub Wiki 卡片，再点击就绪后的产品入口。产品也可以独立运行：
~~~bash
.venv/bin/python -m wiki_app.main
~~~
网页默认 http://127.0.0.1:8601。输入公开 GitHub owner/repo 地址，可填写分支、标签或 commit。生成后通过目录阅读，查看本地引用、导出 Markdown 或针对源码提问。

## 两种阅读模式
- 没有可用模型密钥时使用源码模式，不需要密钥。项目概览摘录 README；Python 静态分析展示声明、显式导入和调用表达式。其他语言提供文档、文件和检索证据。
- 模型模式使用兼容 OpenAI 的 chat/completions API，对选定的源码证据生成中文综合。模型结论仍需核对，引用有效不等于语义正确。

未保存自定义设置时，默认使用 WSL2 的 DeepSeek（deepseek-v4-flash，https://api.deepseek.com）。密钥优先读取 DEEPSEEK_API_KEY 环境变量，否则读取 ~/.bashrc 中该变量的字面量赋值；不会执行 shell 配置，也不会复制密钥。识别到密钥后默认启用模型。\n\n需要其他提供商时，模型密钥通过 WIKI_API_KEY 环境变量提供。重新启动产品以继承环境，然后在网页“模型设置”填写 Base URL（例如提供商的 /v1 地址）与模型名，勾选启用并保存。保存后的设置（包括主动禁用）优先于默认 DeepSeek。密钥不显示在网页，不保存到数据库。不要将密钥写入 Git 文件。
知识研究和配图分阶段调用模型，次数、输出和耗时取决于仓库与当前配置；临时供应商错误采用有界重试。设置变化后点击“重新生成”，旧版本保留。旧源码版本不会自动变成模型版；切换到新版本即可阅读中文生成内容。README 摘录只展示可读文字，原始 HTML 与数字在本地源码证据中完整保留。
如果产品由 AgentOS 启动，环境变量需要设置在启动 AgentOS 的终端；已有产品进程继续使用启动时环境。停掉该产品后再次从控制台打开。

## 数据与恢复
数据默认 var/，包含 SQLite、raw 不可变快照、wiki 版本和 notes 用户笔记。可用 --data-dir 或 WIKI_DATA_DIR 改变位置。产品数据和密钥不进入 Git。
备份时先停止 Wiki 产品，命令拒绝覆盖既有目标：
~~~bash
.venv/bin/python -m wiki_app.backup backup var ../wiki-backup
.venv/bin/python -m wiki_app.backup restore ../wiki-backup ../wiki-restored
.venv/bin/python -m wiki_app.main --data-dir ../wiki-restored --port 8602
~~~
恢复保持记录身份并更换导出 epoch，AgentOS 可以重新对账；不要将恢复副本和原实例同时当成同一个产品同步。

源码采集受压缩包、文本总量、单文件、文件数和扫描量限制；当前规则见 [容量与韧性说明](docs/resilience.md)。覆盖与跳过原因随版本保存，容量上限不代表内容质量保证。
任务在后台串行执行，取消、失败或重启中断可从任务页显式重试。更新成功才切换当前版本，历史回答保留当时引用。Markdown 日志记录版本生成，原始笔记不自动覆盖。


## 架构可视化
打开一个 Wiki 版本，在阅读目录选择“架构可视化”。生成分析不调用模型；切换总览／模块依赖，展开目录、筛选节点，点击关系查看固定源码证据。可导出 PNG、当前筛选 Mermaid 或完整 JSON。
选择文件或模块后可用当前模型解读，结果保留在阅读历史。检查更新只比对远端 commit；生成新版本需点击更新按钮，旧图与旧问答保留。
实现边界、技术栈理由和验收见 [架构视图规范](docs/architecture-views.md)。

## 与仓库讨论
打开 Wiki 正文或架构页，点击右下角“讨论这个仓库”。侧栏支持追问、自由解释、比较与设计讨论；选中图节点/关系会带入当前对象，正文选中后可点“带入选中文字”。点击“仅讨论仓库”可解除当前页面范围。
会话按固定版本保存，可新建、切换、刷新恢复；事实引用可打开本地源码。默认复用已配置模型，未启用时显示配置入口。等待时显示处理状态并可停止，回答校验后完整显示。模型参考最近最多8轮，侧栏显示最近100条记录；旧版本对话不与新版本混用。


### 统一外观

AgentOS侧栏“外观”提供跟随系统、亮色和暗色。设置在本机持久保存，Wiki与Reader自动跟随（可见页面通常3秒内更新，返回标签页时立即检查）。三处界面使用统一系统字体、中性灰颜色与细边框。Reader的原始PDF保持纸张本色。
从AgentOS打开Wiki/Reader时，服务就绪后直接进入产品；启动失败时才显示错误和重试，不再要求二次点击。外观同步服务暂不可用时保留最近主题，阅读不受影响。


## 阅读工作区
聊天栏边缘可拖动调宽；Tab聚焦分隔条后用左右键调整，双击或Enter重置。可切换专注/并排，小屏保留完整入口。输入草稿按会话保存在本机，Enter换行、Ctrl/Cmd+Enter发送，未发送的讨论草稿可从讨论列表恢复。清除浏览器数据会清除本机草稿；正式保存的记录独立保留。

## 适用范围与质量边界
公开 GitHub 仓库可自动推进固定快照、静态分析、Wiki 与配图；不支持私有或本地仓库，不运行输入代码。Python、JS/TS 有专门解析，其他语言主要保留文本检索。源码定位、引用校验、任务恢复、渲染与导出可复用；摘要、架构和跨文件流程仍需抽查，自动审核不能保证正确。
独立样本采集 1642 个文本文件约 22 MB，工程流程完成，内容验收未通过；不能保证任意仓库质量。局部失败保留有效成果并说明原因。详情见 [独立验收](docs/independent-acceptance.md)。
服务重启后旧页面的写入若被明确以 write_token_required 拒绝，会读取同源新页面令牌并仅重试一次；网络结果不明及其他拒绝不会自动重发。

## 完整 Wiki 生成任务
一次导入对应一个生成流程。任务页自动跟随采集、静态分析、正文研究和配图阶段；无需逐个进入后续任务。首页合并显示同一流程，各阶段未完成的原因仍可展开查看。停止作用于当前活动阶段并阻止继续串接；流程结束后可统一继续未完成部分，复用已有缓存。已有 Wiki 可直接阅读，不因局部失败隐藏。
