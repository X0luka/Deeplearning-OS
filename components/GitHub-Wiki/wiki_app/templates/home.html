适用范围与当前能力

支持公开 GitHub 仓库：导入后自动采集固定提交、分析静态结构，在模型可用时生成 Wiki、配图并审核。不支持私有仓库、本地目录，不执行仓库代码。

可用基础能力：源码快照、文件与行号定位、引用校验、任务取消与恢复、图形展示和导出。Python、JavaScript / TypeScript 有专门静态解析；其他语言主要提供原文与检索，不保证同等结构精度。

仍需人工核对：摘要、职责划分、跨文件调用、条件分支和架构图可能遗漏或出错。引用有效只代表原文匹配，自动审核通过不代表结论正确。当前不能保证一键准确解释任意仓库。

容量、失败处理与实测边界

采集受压缩包、文本总量、单文件和文件数限制；二进制、生成文件等可能跳过，实际覆盖以版本记录为准。已实测 1,642 个文本文件、约 22 MB 的快照完成自动流程，但内容质量未全部通过，容量上限不是质量保证。

局部失败保留其他有效成果，显示具体规则、原因和重试入口；影响整个阶段的错误才停止该阶段。临时服务错误有界重试，没有可用模型时保留源码阅读。模型生成会分阶段调用，耗时与费用随仓库和配置变化。
