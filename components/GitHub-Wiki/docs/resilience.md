# Wiki 容量、失败隔离与数据清理（RESILIENCE-20260928）

本轮沿用现有串行任务、固定版本快照与 React Flow/ELK，不以选择性少读源码冒充容量提升。

## 支持目标与实测
默认压缩归档256 MiB、文本128 MiB、单文件4 MiB、20000文件、100000归档条目、1 GiB解压扫描量、下载总时限600秒。参数仍由 WIKI_MAX_* 环境变量覆盖。普通文本以逐文件磁盘快照保存；索引分批插入；结构分析按文件读取，单文件解析15秒保护，分析阶段整体600秒保护。后者是最后的进程保护，未通过则不能宣称分析完成。

单文件/文本量/文件数超限记录为局部缺口，保留其他可用文件；没有有效文本、完整归档无法取得或快照校验失败才阻断依赖阶段。路径不安全、二进制和明确生成产物不会作为源码执行或分析。源码不足不能标记完整覆盖。

真实 deepseek-harness 固定 commit 21638c56315ae6a2b552d6091945d3144c9af32e：13800文本文件，113965198字节，无容量截断，采集索引分析66.7秒。主/子进程峰值分别168364/182700 KiB（各自峰值，不表示同时总量）。独立边界采集：20000文件、127068160字节、4 MiB单文件，7.6秒、71216 KiB峰值。两者均为隔离验收，不表示所有输入都具有相同耗时。

## 生成与错误
目录分批规划研究，不截掉后半目录；超过9个候选主题时跨批次归并职责（优先2–9组，独立核心职责最多16组），验证每个候选恰好归属一次并保留全部入口路径，避免重复生成同类主题。模型按主题取证和补读，最多六轮；独立主题失败继续后续主题。总览失败时保存已核对主题的部分结果；完整旧版不会被部分完成的新结果覆盖，任务明确提示沿用旧版且不错误衔接旧版配图。部分完成任务支持显式重试。连接、读取或协议等临时传输故障最多延迟重试2次；取消、配置和余额错误立即停止相关模型阶段，保留可用源码与已有成果。质量错误走独立修正审核，不套用传输重试。失败原始响应只作诊断；结构/引用校验通过的阶段方可复用。引用必须在允许证据集合内，错误提示具体字段/编号。

GET /api/rules 返回版本化规则及生效容量。GET /api/jobs/{id} 保留 error，增加 failure（规则、作用范围、阶段、对象、上限/观测值、恢复建议）。旧任务也可获得规则解释，但不会虚构历史限额。提醒、局部失败、阶段阻断分别处理；任务成功不代表所有主题均成功，partial 与未完成原因独立保留。

## 仓库删除
GET /api/repos/{id}/deletion-preview 返回版本数量、可清理文件占用、活动任务、保留项及预览指纹。
DELETE /api/repos/{id} 请求 name 与 preview_token，沿用 token/Origin 校验。页面首次打开预览，输入完整仓库名后才能第二次确认永久删除。

有活动任务时拒绝删除；取消并等待退出后重新预览。持久删除回执锁定目标仓库写入，分阶段删除 raw/wiki/任务专属tmp、生成任务和检索索引。每一步校验精确目录及符号链接，失败可继续；不会访问其他仓库目录。
保留 Wiki 问答、引用快照和历史问答任务；来源已删除时仍可阅读历史，源码入口返回410。平台独立会话、已有备份/导出和归属不明的共享缓存/笔记保留，不承诺全盘消除数据。再次导入同URL创建新记录。

文件清理和数据库空间回收分别报告。SQLite 空闲页待队列空闲、磁盘余量充足时整理；维护锁暂停API写入。整理失败或空间不足不会撤销已完成删除。没有自动删除用户仓库或历史备份。

## 后续修复与复验
- 工程判断由维护者负责：传输短暂故障最多三次尝试（追加等待2秒、5秒），用户取消立即生效；鉴权、余额、配置、内容质量问题不套用此机制。
- 审核覆盖完整性在阶段入缓存前校验。真实结论/步骤/连接/职责/边界必须逐项核对；不存在的额外审核对象只记提示，遗漏或重复真实对象进入一次修正。
- 模块职责与边界也纳入独立审核，防止从局部源码推出“项目唯一通道”或“其他实现不存在”。修正后仍不支持的职责/边界替换为范围说明，保留已核对结论并记录局部质量问题。
- 总览边界从当前图的已引用内部/外部节点表达覆盖范围，不生成未经证实的全仓库否定结论；该范围说明仍接受独立源码审核。
- 摘要压缩不满足展示偏好时保留原有带证据正文，不因排版长度让整个总览失败。
- OpenResearch/deepseek-harness 在 acceptance-data-v3 中从固定源码、阶段缓存重新生成；未复制最终知识或手工改图。真实模型审核与配图仍在进行，最终正式更新须以完成后的源码抽查和发布回执为准。

实测产品入口补修：不绘图规划可省略绘图类型与问题；不可用补读提示按 EVIDENCE.READ_HINT_UNAVAILABLE 局部记录，继续从有效引用与关键词检索，不能将提示路径当作引用。大仓库分批规划已覆盖全部候选，但合理归并为12组时曾被9组展示偏好阻断；现保留最多16个独立研究问题，每张图节点/边上限不变，所有候选仍须恰好归属一次，不通过丢弃主题降低复杂度。增加研究主题会增加模型调用和耗时，阶段成功缓存继续复用。

大仓库总览审核的选证也按最终总量限制：分批选出的证据若汇总仍超过65000字符，再分层选择，验证每轮收敛；最终模型输入96000字符保护不放宽。不能只控制单批而让汇总重新溢出。
