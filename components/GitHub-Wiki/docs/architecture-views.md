# AV-001 多视图架构阅读
责任：Agent。授权：本地开发、验证、记录、Git，不推送。额度不足保存恢复点，额度恢复后继续。

## 技术栈与边界
Python/FastAPI/Jinja2 复用服务；Python AST 与 Tree-sitter JS/TS/TSX 提取语法；独立 resolver/graph 聚合事实；Cytoscape 本地资源展示，不参与解析；SQLite 复用任务/记录，JSON 保存版本产物；DeepSeek 仅解读选择范围，不修改关系。
源码解析 → 事实 → 架构分析 → 视图接口 → 总览/依赖，两视图不串行依赖。只分析不可变快照；不执行仓库代码/配置。时序图、城市图、完整 C4 不在首轮范围。

## 数据与更新
分析绑定 Wiki version、commit、分析器版本；节点按路径稳定编号，边保存来源行号。
内容哈希＋语言＋解析器版本缓存语法事实，关系每版本整体重算。配置变化不会错误沿用旧连线。
新图完整写入后原子切换；失败保留旧成功图。图任务与 Wiki 正文独立，无模型仍可生成图。
手动检查远端更新；固定 commit 不跟随分支。检查不调用模型，更新显式创建现有 build 任务。
新增 architecture 任务、GET/POST /api/versions/{id}/architecture、GET export。问答可选 analysis_id/node_id，严格校验归属与证据范围。
图在 wiki/{version}/architecture 下，缓存放 var/cache，可重建。备份覆盖图但无需缓存。原始版本与历史问答不改写。

## 技术选择说明
- 保持 FastAPI/Jinja2/SQLite：复用已有任务、版本、归档与本地部署，避免引入第二套服务和数据库。
- Python AST 提供标准库语法事实；Tree-sitter 覆盖 JS/TS/TSX。tree-sitter 固定 0.25.2：0.26.0 在真实大快照遍历中出现原生进程失败，降级后 1948 个可解析文件完成。
- 解析器只产生语法事实，resolver 单独处理路径与配置，视图层只投影图。未来增加视图可复用事实，需要运行时数据的时序图应另加分析器。
- Cytoscape 3.34.3 在本地提供交互布局与 PNG；Mermaid 用于文本交换；JSON 保留完整事实。vendored 资源附许可证与来源哈希，无 CDN 依赖。
- JSON 原子发布配合 SQLite 任务：失败不覆盖旧图，归档按 analysis_id 查回；语法缓存可重建，不是权威数据。

## 实测与运行说明
AgentOS-K：47 文件、92 边，分析 0.142s。OpenHands：2184 文件、11030 边，分析 4.119s；755 条未解析关系明确标注，不冒充已证实依赖。
缓存视图服务计算：AgentOS aos 约 0.9–1.3ms；OpenHands src/api 约 42–75ms，不等同端到端浏览器渲染时延。
模型证据优先完整保留不超过8片段的小范围；较大范围最多12片段，其中最多4条直接入边导入证据。模型不能修改静态图。
当前机器 AgentOS 启动的服务不继承终端代理。Wiki 的 meta.network_proxy 保存本机代理 http://127.0.0.1:7897；WIKI_HTTPS_PROXY 可覆盖，未配置时沿用进程环境。代理不可用会明确失败，不自动重发模型调用。
