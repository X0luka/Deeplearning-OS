## 评测执行

```sh
uv run python scripts/evaluate.py preflight
uv run python scripts/evaluate.py run --split dev --permit var/evaluation/permit.dev-24.json --output var/evaluation/runs/dev-001
uv run python scripts/evaluate.py score --runs var/evaluation/runs/dev-001
```

批次目录必须不存在，不覆写旧回执；每次请求前先记任务编号。运行结束不自动评分。回执的 `review` 由独立于生成过程的原文审阅补充：`reviewer`、`method=source_checked_by_reviewer`、布尔 `passed` 与 `critical_error`、具体 `rationale`。

没有40题全部回执和逐题原文审查，不会放行阶段A。相同题号的多份回执不能静默覆盖；不同实现候选的结果不能混合。留出集一旦开始尝试即标记使用，失败后不得反复当成独立验证集调优。

## 已发现的解析限制

开发集发现窄栏间距、图注、数学上下标与表格影响线性阅读；已按实际坐标改进分栏，保留旧解析版本。栏序仍为启发式，不能声称任意论文都能正确解析。表格行列与公式二维结构不作为自动验证事实。

## 运行与保护

- 使用 `uv.lock` 锁定独立环境，不复用 Wiki 私有代码或改写产品库。
- 模型许可文件不含密钥；账本在网络请求前预留调用与输出额度，失败不自动退款或重发。
- 输入字节是保守的请求规模限制，不是服务商的精确 token 计数或人民币金额；实际 usage 单独保留。
- `paper-reader recover` 必须取得单 Worker 锁；中断任务标记 interrupted，不能自动重排队。
- 不推送；没有用户界面与宿主服务启动，不能宣称首版完整交付。
