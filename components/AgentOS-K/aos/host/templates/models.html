API 连接

请先输入 API。连接名称由您自定义，系统不会根据名称限定厂商或模型。

添加 API / 编辑连接

填写服务商提供的接口根地址，常见格式为 https://域名/v1，例如 https://api.openai.com/v1；DeepSeek 官方可用 https://api.deepseek.com。兼容 OpenAI 不代表域名相同，也不保证必须带 /v1。不要填写完整的 /chat/completions 地址；软件会在根地址后添加 /models 来读取模型列表。

已有密钥只显示遮罩，不回显原文；编辑时删空并保存会清除密钥，取消编辑不会改变已保存配置。
