# Deeplearning-OS preparation rules

The user authorized development in this independent copy only. Original repositories,
their Git metadata, runtime data, credentials, launchers, services and network settings
must not be modified or restarted. This instruction supersedes historical operational
directions copied from the three source repositories. Those originals are kept locally.

Before running anything, read docs/PREPARATION.md and inspect .local/preparation reports.
Do not execute legacy installers or maintenance commands against the original system.
No production data or personal credentials may be copied. No paid model calls without
an explicit provider, data and cost authorization. No release before readiness gates.
Tests run serially in the provided private namespaces; no production network access.
Never label offline mock tests as real model or desktop acceptance.
Preserve independent component HTTP contracts and existing parsing behavior.
Update docs/PREPARATION.md with results and unverified items. Changes stay here; never
automatically synchronize back to the original repositories.

Component-specific architecture and HTTP contracts remain applicable.
