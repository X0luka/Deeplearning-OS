## 依赖

```text
T01 → T02 → T03
        └→ T04 → T05 → T06
T03 + T06 → T07 → T08 → T09
T08 + 外发/费用许可 → T10
T09 + T10 → T11 本地发布候选
T11 + 对应远端授权 → push / PR / merge / 部署
```

可以顺序交错完成独立任务，不自动启用多 Agent。T10 缺许可时继续 T09；异盘目标未定先完成本地恢复，不把局部缺口扩大为全部阻塞。

任务状态：NOT_STARTED、READY、RUNNING、BLOCKED、VERIFIED。READY 必须同时满足前置证据与当前授权；VERIFIED 必须有 [执行证据](evidence-template.md)。未运行的命令不能打勾。网络、依赖和硬件不保证一定可用，失败须记录实际原因、影响任务及可继续工作，不用 mock 冒充真实通过。

旧阶段映射：P0→T01/T02；P1→T03；P2→T04–T06；P3→T07/T08；P4→T09–T11。旧文档 P0 按此解释。新产品、嵌入网页、自主诊断/修改不在本轮路线，需独立目标。
