## 产品接入与任务约束
Reader 和 Wiki 已在正式桌面会话中以 managed-v1 模式读取平台设置；不再静默回退旧环境变量。独立启动模式保留。产品后端直接请求供应商，AgentOS 不转发提示词或回答。

Reader 保留引用、工具循环、PDF/联网开关和原阅读预算，支持产品/当前会话覆盖。Wiki 分开维护源码对话、证据与架构标注、Wiki 知识生成；后两者保留各自 JSON 校验和输出预算。全局 Custom 只配置一次，不能取代产品固定输出契约。正式当前选择保留 Reader deepseek-flash、Wiki deepseek-v4-flash。

平台密钥位于 var/llm/private（目录 700、文件 600），浏览器与业务记录不返回密钥。配置接口沿用本地来源/CSRF 防护，内部接口按产品鉴权。已接入的 Reader/Wiki 共享所有平台连接，各自不能修改平台或读取对方配置；本版没有连接级访问白名单。凭据轮换使用独立引用，避免请求混用新密钥和旧地址；旧凭据文件可能作为私有残留保留，清除操作停止新请求使用密钥，不承诺安全擦除磁盘历史。

## 恢复与后续
源码基线 bundle 保存在各仓 var/maintenance/LLM-UI-20260920；初始数据库一致性副本位于其 databases 子目录。部署前最新副本、counts.json 与 live-verification.json 位于宿主该目录的 predeploy 子目录。离线集成证据位于宿主 var/verification/LLM-UI-isolated/result.json。

恢复时先确认无忙任务并正常关闭桌面；在独立恢复目录从 baseline.bundle 检出旧版，检查备份完整性后决定切换。旧产品环境和原凭据未删除；代码回退可恢复旧的独立配置方式。禁止覆盖更新后的业务数据库；业务数据恢复须先比较新增记录。平台配置需连同 var/llm/config.db 和 private 作为私有整体备份，不上传仓库。

用户可从 http://127.0.0.1:7777/settings/models 设置连接、全局偏好和任务默认，再在产品内按需覆盖。实际工具/原生 PDF/思考支持仍由模型和适配协议共同决定；额外协议、图像音频生成和通用外部工具市场不在本轮实现范围。真实效果测试由用户主动使用或另行明确调用范围后进行。
