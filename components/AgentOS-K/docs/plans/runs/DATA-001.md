## 数据与知识中心
目标是帮助用户简洁、诚实地查看平台已保存数据。侧栏新增入口 /data，支持问题或回答文字搜索、应用/记录来源筛选、20 条分页、详情和单条 JSON 导出。同步状态折叠显示最近任务与接收时间；未知、失败和中断不显示为成功。页面明确当前仅覆盖已归档问答，不代表完整论文、源码或笔记，也不以保存状态暗示知识已核实。
保留旧 / 概览、/history 详情、模型设置和产品入口；详情返回保留最近一次列表筛选。未加载来源产品时仍可查看和导出档案。打开来源应用仅到应用入口，尚未接入材料精确位置，不伪造回跳。
未添加容量、重复、孤立数据等复杂仪表盘。尚未实现材料目录、标签/知识编辑、跨应用知识复用、中文译读或问题图；它们继续按原规划后续阶段推进。

## 平台服务与数据
新增产品中立 DataCenter 查询服务，Archive 端口提供一次 SQLite 只读事务快照，供页面与 JSON 接口共用。默认汇集 product_ui 与 legacy_unknown，诊断记录不混入个人记录。搜索是本地参数化普通文字匹配，覆盖问题和回答，不承诺大规模全文检索性能。
没有新增表、迁移 schema、修改产品数据或模型配置。修复读取投影中可选 payload 覆盖归档身份的隐患，以宿主存储列确定 archive_id、product、source_channel 和回退状态；数据库原文不变。显示对文字转义，来源链接只接受有效 HTTP(S)。
