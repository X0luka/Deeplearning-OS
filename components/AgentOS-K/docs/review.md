## 审阅发现与修订

1. 旧设计不使用向量数据库，但真实产品依赖 Qdrant：已明确保留，不引入接入之外的替换工程。
2. 原网页会话无法仅靠 AgentOS 发起请求捕获：源端持久化与变更导出成为核心路径。
3. 只拉最大 ID 会漏完成与反馈更新：采用同事务变更日志与幂等游标。
4. 旧数据无法证明来自网页，也没有线程 ID：保留 legacy_unknown，不伪造分类。
5. HTTP 客户端资源限制保护不了 RAG 内部工作：标明外部执行及产品级限制，逐任务改造后置。
6. 源库恢复后自增 ID/事件号可能复用：补充稳定 record_uid，epoch 只用于事件流；同记录重新对账，避免整库重新导入形成重复会话。
7. P1 先调用而 P2 才有来源标记：明确 P0/P1 使用独立测试实例与数据，不污染生产历史。
8. 相对上传路径依赖 UI/API 共享目录：运行手册明确 cwd 与挂载要求，DATA_DIR 单项设置不等于全路径迁移。
9. 原 CI 未测会话可靠性：远端绿色仅作原单元测试证据，新验收单列。
10. 文档初次链接检查发现 review.md 尚未生成：本报告补齐后重新检查全部链接。
